The problem

Fraud now reaches people through their phone, in their language, in minutes

India moves more than 10 billion UPI payments a month (NPCI public data). Scammers follow the money.

  • Social engineering beats technology. Fake "KYC blocked" SMS, forged .gov.in and bank links, UPI collect-request traps, and "digital arrest" video calls pressure people into sending money or an OTP themselves.
  • Victims decide in seconds, alone. Official advice (RBI, I4C 1930 helpline, cybercrime.gov.in) exists but is not at hand at the moment of the call or the click.
  • Tools are English-first and rule-bound. Real scams arrive in Hinglish, Hindi and mixed script, with no trigger words, and a lookalike domain may not exist yet in any blocklist.
Our target: a check a person or a bank can run in seconds, that says what is wrong, why, and what to do next, and that never pretends to be sure when it is not.
No statistics beyond the NPCI scale figure are quoted here on purpose. See slide 10 for our own measured results.2

How Gen AI is used

Gemini reasons about the hard cases. It does not get the last word.

What Gemini does (Gemini 2.5 Flash, Vertex AI, asia-south1)

  • Second opinion on ambiguous scores (30-70, and low scores that carry a concrete ask) for messages and suspicious domains.
  • Hindi / English advisor: structured JSON (risk, signals, reasoning, action), schema-validated.
  • Translation of verdict text to Hindi, as the last step.

What Gemini does NOT do

  • Never marks an unverified domain as safe.
  • Can raise risk only when the text has a concrete signal (link, number, payment or credential ask). Can lower it only if every signal is purely stylistic.
  • Never sees the user's phone, Aadhaar, PAN, card, e-mail, UPI ID or OTP-like codes: redacted before the call.
Guardrails: user text is quoted as untrusted data (prompt-injection resistant) · 4 s hard timeout, fails open to the rules verdict · every response labels its engine ("Gemini live" vs "rules fallback") · output validated before use.
Source: lib/textAi.js, lib/geminiAdvisor.js, lib/redact.js, README.md.6

Responsible AI, privacy and security

Minimise data, label uncertainty, harden the edges

  • Privacy notice in the UI and a DPDP-oriented design (hash-only audit, purpose limitation). Not legal advice; open items are listed in the repo.
  • Data in India: Cloud Run, Firestore, BigQuery, Gemini and the Document AI OCR processor all run in asia-south1 (Mumbai). Only domain names (never the message) go to public DNS, RDAP and Web Risk.
  • No raw input stored. Audit rows hold a SHA-256 of the input and an HMAC of the client /24 network.
  • PII redacted before any Gemini call.
  • Abuse resistance: token-bucket rate limits per route group, 64 KB JSON and 5 MB upload caps, file-type allow-list, temp-file deletion.
  • Web hardening: SSRF guard on TLS probes, CSP without inline scripts, HTML-escaped output, HSTS, same-origin CORS.
  • Crowd reports are scored on independent corroboration plus engine evidence, with reporter reputation; reports against allow-listed, government or well-established domains always go to human review and can never auto-block them.
  • Fail closed: any network failure reads "could not verify".
Source: README.md, docs/audit.md, lib/redact.js, public/privacy.html.9

Scalability and feasibility

Serverless by design; cost is dominated by the few Gemini calls

  • Stateless Cloud Run autoscales on request load; threat data is an in-memory index (O(1) lookups) refreshed from Firestore, so no datastore call per check.
  • Cheap path first: rules answer most checks in milliseconds; Gemini is consulted only on ambiguous ones (9 of 150 in our evaluation).
  • Known limits: rate limits are per instance (Cloud Armor recommended for a global cap, not enabled); scale-to-zero means occasional cold starts.
Cost sketch (ESTIMATE, not a measured bill)
Assume ~600 input + ~200 output tokens per Gemini call at the public Gemini 2.5 Flash list price (about US$0.30 / US$2.50 per 1M tokens): roughly US$0.0007 per call. If about 6% of message checks consult Gemini, that is roughly US$0.04 per 1,000 message checks for Gemini. Cloud Run compute, Web Risk and Document AI (per page) are extra and small at pilot volumes; confirm against the current Google Cloud price list.

Business viability and bank-pilot path

Start in shadow mode: prove value before touching a customer

PHASE 1 · SHADOWBank sends customer-facing messages and links to the API; SafeMeAI scores silently. No customer impact.
PHASE 2 · MEASURECompare against the bank's confirmed fraud cases. Agree a false-positive budget before anything is shown.
PHASE 3 · ASSISTWarnings in app or SMS banners for high-confidence verdicts only.
  • Interface ready: API keys with a pilot tier, batch scoring, audit trail with input hashes. SLO targets (not guarantees): 99.9% availability, text p95 < 800 ms, domain p95 < 4 s.
  • Before any commercial launch: confirm licences for the Tranco and URLhaus feeds, replace or license OpenPhish (currently not used), finish the DPDP checklist (DPO, breach runbook, processor agreement).
  • Honest status: a prototype. No customers, pilots or revenue to report.
